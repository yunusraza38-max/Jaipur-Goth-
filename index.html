Link Google Drive Storage

Connect your Google account for Drive folder sync

Google Drive mein auto-save kaise karein:

  1. Google Cloud Console mein Google Drive API enable karein.
  2. OAuth 2.0 Web Client ID banayein aur niche paste karein.
  3. Sign in karte hi aapke Drive mein RazaScan_Cloud_Backups folder ban jayega.

Install App / Generate Clean APK

Zero Virus Warning • Official PWA Packaging

Option 1: Direct Install in Chrome (1-Tap)

Chrome menu (⋮) kholein aur "Install App" ya "Add to Home Screen" par tap karein. Yeh bina kisi APK ke asli Android app ban kar install ho jayegi.

Option 2: Clean .APK File via PWABuilder.com

  1. Is file ko index.html naam se save karke Netlify Drop ya GitHub Pages par upload karein (HTTPS link milega).
  2. PWABuilder.com par apna HTTPS link paste karein aur Package for Android par click karke clean .apk download karein.
